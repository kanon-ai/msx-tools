# MSX Tools

MSX向けの制作・検証に使うツールを保存するリポジトリです。各ツールは個別のフォルダーに置き、使い方と依存関係をその中で管理します。

| ツール | 用途 |
| --- | --- |
| [MSX Image Converter](image-converter/README.md) | 一般画像をTMS9918AのPCG・SCREEN 2、またはV9968用16色4bpp画像へ変換 |

今後のツールはルート直下へ専用フォルダーを追加し、この一覧に登録します。BIOS、入力素材、生成物、個人設定は保存しません。
